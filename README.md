# Agentic Tutorial

Short, hands-on notebooks for building agentic AI workflows with PydanticAI

## Notebooks

- `NB01_outputs.ipynb` - structured outputs with raw LLM calls and PydanticAI.
- `NB02_tools.ipynb` - tool calling and agent traces.
- `NB03_validators.ipynb` - Pydantic validators for reliable extraction.
- `NB04_multiagent.ipynb` - multi-agent extraction and summarisation.
- `NB05_ml_agent.ipynb` - ML agent workflow.
